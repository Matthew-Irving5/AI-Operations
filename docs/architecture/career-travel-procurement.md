# Career, Travel, and Procurement boundaries

Career GitHub sync is strictly read-only. Its runtime endpoint has no owner input and uses the fixed `Matthew-Irving5` endpoint; repository payload owners are checked again before data is written. `BrightSG` is a hard denial and cannot appear in stored career evidence.

Career market claims, travel plans, and procurement recommendations retain a source URL and retrieval timestamp. A report is not valid without citations for current claims.

Travel and procurement research are individual on-demand runs. A run records a hard AI-spend cap, maximum web searches, and a model ceiling of Luna or Terra. Watches are associated with the originating run, expire, and notify only on a changed trigger fingerprint. Neither workflow books travel or purchases items.
